# ☕ Maple & Bean Coffee — Business Website

> A responsive, modern coffee shop website built with a focus on clean UI, responsive layouts, and practical business functionality.

[![Live Demo](https://img.shields.io/badge/Live-Demo-000?style=for-the-badge\&logo=googlechrome\&logoColor=white)](https://mapleandbean.infinityfree.io/)

## ⚡ Overview

**Maple & Bean Coffee** is a responsive business website designed to establish a professional online presence for a coffee shop.

The project focuses on:

* 🎨 Modern and responsive UI
* 📱 Mobile-first layout
* ⚡ Fast and lightweight frontend
* 🧩 Structured business content
* 🔧 Easy content customization
* 🌐 Production deployment
